# onepiece-frontend

Frontend (Next.js 16, React 19, Tailwind 4) de One Piece App. CRUD de personajes y atletas, autenticación JWT, subida de fotos a Cloudinary y estadísticas.

## Correrlo

```
npm install
npm run dev
```

Abre http://localhost:3001. Espera el backend en `http://localhost:3000` (no usa variables de entorno).

> Consulta el README principal del proyecto en `../onepiece-app/README.md`.
